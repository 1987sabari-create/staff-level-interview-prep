
## A coding interview framework (UMPIRE-style, adapted)

**1. Understand (1-2 min)**
- Restate the problem out loud in your own words.
- Ask 2-3 clarifying questions: input constraints (size, range, duplicates?), edge cases (empty input, negatives?), expected output format.
- This alone fixes a lot of "scattered" starts — most candidates jump to coding before they've locked the actual problem.

**2. Match / Match to pattern (1 min)**
- Say out loud what category this smells like: "this looks like a sliding window" / "this is a graph traversal" / "this smells like DP." Naming the pattern early anchors your thinking and signals to the interviewer you're reasoning systematically, not guessing.

**3. Plan (2-3 min)**
- Talk through the approach in plain English *before* touching code — brute force first if needed, then the optimization, and state the target time/space complexity.
- This is the step most likely to get skipped under pressure — force yourself to stay here even when you're itching to type.

**4. Implement (10-15 min)**
- Code it, narrating as you go (ties into what you're already practicing).
- If you get stuck, say so out loud and fall back to the plan step — "let me reconsider the approach" is a good recovery line, better than silent panic.

**5. Review (2-3 min)**
- Trace through with a real example, out loud.
- Check edge cases explicitly (empty, single element, all same value).

**6. Evaluate (1 min)**
- State final time/space complexity and one thing you'd improve with more time.

## Why this should help your specific problem
"Scattered" usually means your brain jumps between steps non-linearly under pressure — half-planning, then coding, then realizing you misunderstood the problem, then re-planning mid-code. A fixed framework gives you a rail to hold onto so each phase gets its own dedicated attention, and jumping ahead becomes a visible/nameable mistake ("wait, I skipped planning") rather than an invisible drift.

**Practical way to build the habit:** for the next 2 weeks of coding practice, literally write "U M P I R E" at the top of your scratch space/notes for every problem and force yourself to touch each letter before moving to the next — even a rushed one-line plan is better than skipping the step. After 2 weeks it should start happening automatically without needing the prompt.
